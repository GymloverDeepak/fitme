# FITME v1.1.0

Offline Android fitness app by **Gymlover Deepak**. No account, no ads, no internet needed for its features.

## What's new
- **Advanced Workout Library** — 72 exercises (Beginner, Intermediate, Advanced) with search and filters for difficulty, muscle group and equipment.
- **Advanced plans** — Push/Pull/Legs (6 days), Upper/Lower (4 days) and Bro Split (5 days).
- **Edit your workouts** — add, remove and reorder exercises; change sets, reps, rest and warm-up sets. Reset to the built-in plan any time.
- **Set tracking** — tick off each working set during a session; warm-up sets are shown separately.
- **Exercise demonstrations** — every exercise has its own animated demonstration with play/pause and start/end positions.
- **Deadlift Training Planner** — conservative weight calculator, warm-up sets, plates per side, pre-lift safety checklist, RPE logging, session notes, next-session advice and personal records. No max testing; weights never increase automatically.

## Install
1. Download `FITME-v1.1.0.apk` below on your Android phone (Android 7.0 or newer).
2. Open it. If Android asks, allow installs from your browser or file manager for this one app.
3. Tap **Install**, then **Open**.

**Upgrading from an earlier test build:** this is the first release signed with FITME's own release key. If an older FITME test build is installed, Android will not update it — uninstall the old app first (this removes its saved data), then install this version. Future releases will update normally and keep your data.
